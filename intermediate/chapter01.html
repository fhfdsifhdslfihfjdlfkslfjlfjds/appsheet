1-1 中級編で作るアプリと学ぶこと

中級編では、「勤怠管理アプリ」 を1本完成させます。 社員が出勤・退勤をスマートフォンから打刻し、勤務時間を自動計算。休暇申請もアプリ内で完結させる実用的なアプリです。

初級編で学んだ基本操作（Data / Views / Actions / Automation）をベースに、Valid If による入力制御、Slice によるデータ絞り込み、実用関数、Format Rules による条件付き書式、Action によるボタン操作 など、一歩進んだテクニックを身につけます。

アプリ名：勤怠管理アプリ

目的：社員の出退勤記録・勤務時間の自動計算・休暇申請の管理

使用場面：社員がスマホから出退勤を打刻し、管理者が勤務状況を一覧確認する

データソース：Google スプレッドシート（3シート構成）

前提条件：初級編（備品管理アプリ）を修了していること

■ 中級編で学ぶ主なテーマ

💡 POINT ─ 初級編の知識が前提です
中級編では、初級編で解説した「Data / Views / Actions / Automation / デプロイ」の基本操作は省略します。 もしこれらの操作に不安がある場合は、初級編を先に完了してから中級編に進んでください。

1-2 初級編との違い ─ ステップアップのポイント

初級編と中級編の違いを把握しておくと、学習のポイントがつかみやすくなります。

🌱 初級編（備品管理アプリ）

  • テーブル：2つ（備品一覧・貸出履歴）
  • リレーション：単純なRef（1対多）
  • 入力制御：なし
  • データ絞り込み：なし
  • 関数：TODAY() / UNIQUEID() 程度
  • 見た目：テーマカラー変更のみ
  • Automation：メール通知1つ

🚀 中級編（勤怠管理アプリ）

  • テーブル：3つ（社員マスタ・勤怠記録・休暇申請）
  • リレーション：複数Ref＋マスタ参照
  • 入力制御：Valid If で動的フィルタ
  • データ絞り込み：Slice でユーザー別表示
  • 関数：IF / IFS / HOUR / TEXT / CONCATENATE 等
  • 見た目：Format Rules で条件付き書式
  • Action：退勤打刻・承認・差戻しボタン
  • Automation：複数条件Bot・承認通知
💡 補足
中級編で新しく学ぶ機能（Valid If / Slice / Format Rules / Action など）は、すべて初級編で使った AppSheet エディタの同じ画面内で設定できます。新しいツールを覚えるのではなく、同じツールの「より深い使い方」を学ぶイメージです。

💡 補足 ─ マスタテーブルとは？
社員マスタ のように、基本情報を一元管理し、他のテーブルから参照されるテーブルを「マスタテーブル」と呼びます。 初級編の「備品一覧」も実質的にマスタの役割でしたが、中級編では「社員」という共通のマスタを 勤怠記録と休暇申請の両方から参照 する構造になります。これが「複数Ref」の実践です。
💡 POINT ─ 勤務時間の自動計算
勤怠記録テーブルの「勤務時間」は、スプレッドシートに手入力するのではなく、AppSheet の Virtual Column（仮想列）と関数 で自動計算します。 出勤時刻と退勤時刻から勤務時間を算出する式は、第5章で詳しく解説します。

💡 POINT ─ マニュアルの使い方
初級編と同じく、このマニュアルは 上から順番に読み進めるだけ で実際に動くアプリが完成するように構成されています。 各章で「ここを操作してください」と指示がある箇所では、実際に AppSheet を開いて一緒に操作してみてください。 「読む」のではなく「作りながら学ぶ」 のが最も効果的です。
💡 補足：練習用ファイルについて
本ページ上部の「練習用ファイル」セクションから、サンプルデータ入りのスプレッドシートをダウンロードできます。 ゼロから入力する必要はありませんので、ご安心ください。 また、答え合わせ用として完成済みアプリのリンクも用意しています。途中でわからなくなった場合は、完成形と見比べて確認できます。
⚠️ 注意 ─ 無料プランで完結します
中級編のすべての機能は、AppSheet の 無料プラン（プロトタイプ状態） で動作確認できます。 有料プランが必要な機能（デプロイ等）は各章で明記していますが、学習の完了には有料プランは不要です。
