2-1 スプレッドシートでデータを準備する

第1章で設計した3テーブル（社員マスタ・勤怠記録・休暇申請）をGoogleスプレッドシートに作成します。

💡 POINT ─ 練習用ファイルを使う場合
第1章の「練習用ファイル」からサンプルデータ入りのスプレッドシートをコピー済みの方は、以下のデータ入力手順をスキップして 2-2「AppSheetアプリを生成し、テーブルを取り込む」 に進んでください。

■ 新しいスプレッドシートを作成する

1

Google ドライブ（https://drive.google.com）を開きます。

2

左上の 「+ 新規」→「Google スプレッドシート」→「空白のスプレッドシート」 をクリックします。

3

ファイル名を 「勤怠管理アプリ_データ」 に変更します。

■ シート①「社員マスタ」を作成する

1

画面下部のシートタブ名「シート1」をダブルクリックして、「社員マスタ」 に名前を変更します。

2

下の枠内をすべて選択してコピーし、スプレッドシートの A1セル に貼り付けてください。

社員ID	氏名	部署	メールアドレス	入社日
E001	田中太郎	営業部	tanaka@example.com	2022/04/01
E002	佐藤花子	総務部	sato@example.com	2023/04/01
E003	鈴木一郎	開発部	suzuki@example.com	2021/10/01
E004	高橋美咲	営業部	takahashi@example.com	2024/04/01
E005	伊藤健一	開発部	ito@example.com	2022/10/01

■ シート②「勤怠記録」を作成する

1

画面下部の 「＋」 ボタンをクリックして新しいシートを追加し、名前を 「勤怠記録」 に変更します。

2

下の枠内をコピーし、A1セルに貼り付けてください。

記録ID	社員ID	日付	出勤時刻	退勤時刻	メモ
A001	E001	2026/04/01	9:00	18:00

A006	E001	2026/04/02	9:00	20:00	残業
A007	E002	2026/04/02	8:30	17:00

A009	E001	2026/04/03	9:00	19:30	残業

💡 補足 ─ さまざまな勤務パターンのテストデータ
サンプルデータには、第5章（関数）と第6章（Format Rules）の動作確認ができるよう、以下の4パターンを含めています。
・残業あり（9時間以上）：A006（11h）、A009（10.5h）
・通常勤務（8〜9時間）：A001（9h）、A003（9.25h）、A004（9h）、A005（9h）、A007（8.5h）
・時短勤務（8時間未満）：A002（7h）、A010（4.5h）
・勤務中（退勤時刻が空欄）：A008

■ シート③「休暇申請」を作成する

1

同様に新しいシートを追加し、名前を 「休暇申請」 に変更します。

2

下の枠内をコピーし、A1セルに貼り付けてください。

V005	E004	2026/04/03	特別休暇	2026/05/01	2026/05/02	研修参加	申請中

■ データ入力の確認

  • スプレッドシートのファイル名を「勤怠管理アプリ_データ」に設定した
  • シート名が「社員マスタ」「勤怠記録」「休暇申請」の3つになっている
  • 各シートの1行目にヘッダー行（項目名）が入力されている
  • 「社員マスタ」に5名分のデータがある
  • 「勤怠記録」に10件分のデータがある
  • 「休暇申請」に5件分のデータがある
  • セルの結合を使っていない
  • データの途中に空白行がない

2-2 AppSheetアプリを生成し、テーブルを取り込む

スプレッドシートからAppSheetアプリを生成し、3つのテーブルをすべて取り込みます。

■ アプリを作成する

1

「勤怠管理アプリ_データ」スプレッドシートを開きます。

2

メニューバーの 「拡張機能」→「AppSheet」→「アプリを作成」 をクリックします。

3

AppSheetエディタが開き、最初のシートのテーブルが自動で取り込まれます。

■ 残りのテーブルを追加する

アプリ作成直後は1つのテーブルしか取り込まれていない場合があります。残りのテーブルを追加します。

1

左ナビゲーションの 「Data」 をクリックします。

2

テーブル一覧の左上にある 「+」（Add new table） をクリックします。

3

「Google Sheets」 を選択し、同じスプレッドシート内の未追加シートを選んで 「Add」 をクリックします。

4

3つのテーブル（社員マスタ・勤怠記録・休暇申請）がすべて表示されるまで繰り返します。

⚠️ 注意
既に3つのテーブルが自動で取り込まれている場合は、追加操作は不要です。Data画面のテーブル一覧を確認してください。

2-3 カラム型（データ型）を設定する

各テーブルのカラム型を確認・修正します。初級編と同じ要領ですが、中級編では Time型（時刻）や Email型 など、新しい型も使用します。

■ 「社員マスタ」テーブルのカラム型

カラム名設定するTYPEKEYLABEL補足
社員IDText✅ ON—一意のID
氏名Name—✅ ONアプリ上の表示名になる
部署Enum——営業部 / 総務部 / 開発部
メールアドレスEmail——Automation のメール送信先に使用
入社日Date——日付型

■ 「勤怠記録」テーブルのカラム型

カラム名設定するTYPEKEYLABEL補足
記録IDText✅ ON✅ ONInitial Value に UNIQUEID() を設定
社員IDRef——⭐ 2-4 で Ref 設定（参照先：社員マスタ）
日付Date——勤務日
出勤時刻Time——時刻型（HH:MM）
退勤時刻Time——空欄 = 勤務中
メモText——備考欄

■ 「休暇申請」テーブルのカラム型

カラム名設定するTYPEKEYLABEL補足
申請IDText✅ ON✅ ONInitial Value に UNIQUEID() を設定
社員IDRef——⭐ 2-4 で Ref 設定（参照先：社員マスタ）
申請日Date——申請を行った日付
休暇種別Enum——有給休暇 / 慶弔休暇 / 特別休暇
開始日Date——休暇の開始日
終了日Date——休暇の終了日
理由Text——申請理由
承認ステータスEnum——申請中 / 承認済み / 差戻し
1

各テーブルをクリックし、上記の表の通りに TYPE を確認・修正します。

2

すべて設定したら、右上の 「Save」 ボタンで保存します。

💡 POINT ─ Time 型について
初級編では使わなかった Time 型 が登場します。Time 型は「09:00」「18:30」のような時刻データを扱う型です。Date 型（日付）とは異なり、時分のみを管理します。出勤時刻・退勤時刻のカラムに設定してください。
💡 補足 ─ Email 型のメリット
社員マスタの「メールアドレス」を Email 型 に設定すると、アプリ上でメールアドレスをタップしたときに自動でメール作成画面が開きます。また、第8章の Automation でメール送信先として直接参照できるようになります。

2-4 Ref（リレーション）を設定する

「勤怠記録」と「休暇申請」の両方から「社員マスタ」を参照する 複数Ref を設定します。これが中級編のデータ設計の核心です。

🕐 勤怠記録
記録ID（KEY）
社員ID → Ref（社員マスタ）
日付 / 出勤時刻 / 退勤時刻 …
Ref
👤 社員マスタ
社員ID（KEY）
氏名（LABEL）
部署 / メールアドレス …
Ref
📝 休暇申請
申請ID（KEY）
社員ID → Ref（社員マスタ）
休暇種別 / 承認ステータス …

■ 「勤怠記録」テーブルの社員IDにRefを設定する

1

Data → 「勤怠記録」 テーブルのカラム一覧を開きます。

2

「社員ID」 の TYPE をクリックし、「Ref」 を選択します。

3

「Source table」 で 「社員マスタ」 を選択し、「Done」 をクリックします。

4

右上の 「Save」 で保存します。

■ 「休暇申請」テーブルの社員IDにRefを設定する

1

同様に Data → 「休暇申請」 テーブルの 「社員ID」 の TYPE を 「Ref」 に変更します。

2

「Source table」 で 「社員マスタ」 を選択し、「Done」 → 「Save」 で保存します。

💡 POINT ─ 複数Refのメリット
「社員マスタ」をRefで参照することで、以下のメリットがあります：
・勤怠記録・休暇申請の入力時に、社員名を ドロップダウンから選択 できる
・社員マスタの詳細画面から、その社員の 勤怠記録と休暇申請を一覧表示 できる
・社員の氏名や部署が変更されても、参照先（社員マスタ）を1箇所修正するだけ で全テーブルに反映される
💡 補足 ─ Virtual Column の自動生成
Refを設定すると、「社員マスタ」テーブルに Virtual Column（Related 勤怠記録s / Related 休暇申請s）が自動生成されます。これにより、社員の詳細画面にその社員の勤怠記録と休暇申請がインラインで表示されるようになります。

2-5 Initial Value と KEY / LABEL を設定する

初級編と同様に、KEY列の Initial Value に UNIQUEID() を設定します。中級編では2つのテーブルに設定が必要です。

■ 設定対象

テーブルカラムInitial Value説明
勤怠記録記録IDUNIQUEID()新規打刻時にIDを自動生成
休暇申請申請IDUNIQUEID()新規申請時にIDを自動生成

■ 設定手順（2テーブル分繰り返し）

1

Data → 対象テーブルのカラム一覧で、KEYカラム（記録ID / 申請ID）の 鉛筆マーク（✏️ Edit） をクリックします。

2

詳細設定パネルを下にスクロールし、「Initial value」 に UNIQUEID() と入力します。

3

右上の 「Save」 で保存します。

⚠️ 注意 ─ この設定を忘れないでください
Initial Value を設定しないと、アプリからデータを追加したときにKEY列が空になり、行の追加に失敗します。「勤怠記録」と「休暇申請」の両方 に設定してください。

■ 追加の Initial Value 設定

利便性を上げるために、以下のカラムにも Initial Value を設定しておきましょう。

テーブルカラムInitial Value効果
勤怠記録日付TODAY()新規打刻時に今日の日付が自動入力
勤怠記録出勤時刻TIMENOW()新規打刻時に現在時刻が自動入力
休暇申請申請日TODAY()新規申請時に今日の日付が自動入力
休暇申請承認ステータス"申請中"新規申請時に「申請中」が自動入力
1

上記の各カラムの鉛筆マーク（✏️ Edit）をクリックし、「Initial value」 に式を入力します。

2

すべて設定したら 「Save」 で保存します。

💡 POINT ─ TIMENOW() とは？
TIMENOW() は、実行された時点の「現在時刻」を返す関数です。TODAY()（今日の日付）と組み合わせることで、出勤打刻ボタンを押した瞬間の日付と時刻が自動記録されます。

■ ID列をユーザーに見せない（SHOW? の設定）

社員ID・記録ID・申請IDなどの KEY列 は、AppSheet がデータを内部管理するために必要ですが、アプリを使う人にとっては意味のない英数字の羅列です。これらを画面に表示したままだと、一覧画面や詳細画面が見づらくなります。

💡 ポイント：KEY列の「SHOW?」をOFFにしても、データは削除されません。あくまで画面上の表示・非表示だけが変わります。
1

左メニューの Data をクリックし、対象テーブル（例：社員マスタ）を選択します。

2

カラム一覧で 「社員ID」 の行にある SHOW? のトグルを OFF（灰色）にします。

⚠ 警告メッセージが出ても問題ありません： SHOW? を OFF にすると、画面上部にオレンジ色の警告メッセージ「Column Name '社員ID' in Schema '…' was set to be unsearchable because it is 'Hidden'」が表示されることがあります。これは「非表示にしたカラムは検索対象から外しました」という通知で、エラーではありません。そのまま作業を続けて問題ありません。
3

同様に、勤怠記録 テーブルの「記録ID」、休暇申請 テーブルの「申請ID」も SHOW? を OFF にします。

4

右上の Save をクリックして保存します。

以下の表に、各テーブルで非表示にすべきカラムをまとめます。

テーブル カラム名 SHOW? 理由
社員マスタ 社員ID OFF 内部管理用のKEY。ユーザーに見せる必要なし
勤怠記録 記録ID OFF UNIQUEID() で自動生成されるKEY
休暇申請 申請ID OFF UNIQUEID() で自動生成されるKEY
📌 初級編との違い：初級編では ID列の非表示設定に触れませんでしたが、テーブル数が増えると ID だらけの画面になりがちです。中級編では「ユーザーに見せる情報」と「システムが管理する情報」を意識的に分けることが重要です。

2-6 ビューを作成して動作確認する

データ設定が完了したら、基本的なビューを作成してプレビューで動作確認します。

■ 各テーブルのビュー設定

ビュー名View typePosition補足
勤怠記録tablefirstホーム画面。出退勤データを表形式で表示
休暇申請tablenext休暇申請を表形式で表示。承認ステータスが一覧で確認しやすい
社員マスタtablenext社員一覧。管理者が社員情報を確認する用
1

左ナビゲーションの 「App」→「Views」 を開きます。

2

各ビューの View type と Position を上記の表の通りに設定します。

3

右上の 「Save」 で保存します。

■ プレビューで動作確認

設定が完了したら、プレビューで以下を確認してください。

  • ナビゲーションに「勤怠記録」「休暇申請」「社員マスタ」の3つが表示されている
  • 勤怠記録の一覧にサンプルデータが表示されている
  • 勤怠記録の「＋」ボタンをタップすると、社員IDがドロップダウンで選択できる
  • 社員マスタの任意の社員をタップすると、詳細画面にその社員の勤怠記録と休暇申請がインライン表示される
  • 休暇申請の一覧にサンプルデータが表示されている
⚠️ 注意
社員IDのドロップダウンに社員名が表示されない場合は、社員マスタの 「氏名」カラムが LABEL に設定されているか を確認してください。
